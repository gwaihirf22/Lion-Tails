The solution is to refactor your code to use the **iterative, "outline-then-chapters" generation method**.

Here is a breakdown of the issues and a complete, refactored version of your `generateStoryWithOpenAI` function that implements this superior strategy.

### Analysis of Your Current Code

1.  **Core Issue: Single API Call:** The entire story generation happens in one `openaiClient.chat.completions.create` call. The AI completes the narrative arc (beginning, middle, end) and stops, ignoring the word count because it fulfilled the *story* request.
2.  **Invalid `max_tokens`:** In your debug data, you have `maxTokens: "unlimited"`. This is not a valid parameter for the OpenAI API. When you make the API call, you aren't actually setting `max_tokens` at all. This means the API is using its default, which is very small (often around 256 or 512 tokens), cutting your story short regardless of your prompt. The correct approach is to set it to the model's maximum, like `4096`.
3.  **Overly Complex Prompts:** Your `system` and `user` prompts are trying to do everything at once: set the persona, define the JSON structure, give the plot, specify the length, and list stylistic rules. This can confuse the model and lead it to prioritize certain instructions (like "finish the story") over others (like "make it 3000 words").

---

### The Refactored Solution: Outline -> Chapters -> Finalize

I have rewritten your `generateStoryWithOpenAI` function and broken it into smaller, more manageable helper functions. This new structure will reliably produce stories of the desired length.

**What this new code does:**
1.  **`generateStoryOutline`:** First, it asks the AI to generate *only* a detailed, chapter-by-chapter outline for the story.
2.  **Chapter Loop:** It then loops through each point in the outline. In each loop, it calls `generateStoryChapter`, feeding it the story *so far* and asking it to write only the *next* chapter.
3.  **`finalizeStoryDetails`:** After all chapters are written and combined, it makes one last call to generate the final details like the title, application questions, and image prompt based on the complete text.
4.  **Fixes `max_tokens`:** All API calls now correctly include `max_tokens: 4096`, giving the AI ample room to write.

async function generateStoryOutline(client: OpenAI, request: StoryRequest, wordCount: number, moralOutcome: string, debugData: any[]): Promise<string[]> {
  const { childName, theme, biblicalEvent } = request;

  const systemPrompt = `You are a master Christian children's storyteller. Your task is to create a detailed plan for a story.`;
  const userPrompt = `
    Please create a chapter-by-chapter outline for a Christian children's story.
    The story should be approximately ${wordCount} words long in total.
    
    Story Details:
    - Main Character: ${childName || 'A child'}
    - Core Theme: ${theme || 'Faith and kindness'}
    - Biblical Tie-in: ${biblicalEvent && biblicalEvent !== 'none' ? `references the story of ${biblicalEvent}` : 'General Christian values'}
    - Moral Outcome: ${moralOutcome}

    Instructions:
    Create an outline with 5-7 parts. Each part should describe a scene or chapter.
    The outline should naturally progress the story from introduction, to conflict, to resolution, reflecting the chosen moral outcome.

    Respond with ONLY a valid JSON object in the format: { "outline": ["Chapter 1 description...", "Chapter 2 description...", ...] }
  `;

  const response = await client.chat.completions.create({
    model: "gpt-4o",
    messages: [{ role: "system", content: systemPrompt }, { role: "user", content: userPrompt }],
    response_format: { type: "json_object" },
    temperature: 0.7,
    max_tokens: 1024 // More than enough for an outline
  });
  
  const responseContent = response.choices[0].message.content || '';
  debugData.push({ step: 'generateOutline', prompt: userPrompt, response: responseContent });

  const json = JSON.parse(responseContent);
  return json.outline;
}


async function generateStoryChapter(client: OpenAI, request: StoryRequest, chapterOutline: string, storySoFar: string, moralOutcome: string, debugData: any[]): Promise<string> {
    const { readingLevel } = request;
    const wordCountPerChapter = getWordCountFromLength(request.storyLength || "medium") / 5; // Divide total words by ~5 chapters

    const systemPrompt = `You are a talented Christian children's story author. Continue writing a story based on the context provided.
    - Write in a style appropriate for the reading level: ${readingLevel || 'early-elementary'}.
    - Focus ONLY on writing the current part of the story. 
    - Do NOT summarize. Do NOT add a title or application questions.
    - Do NOT conclude the entire story unless the outline explicitly says this is the final chapter.
    - Seamlessly continue from the 'Story So Far'.`;
    
    const userPrompt = `
      Here is the story so far:
      ---
      ${storySoFar || "This is the very first chapter."}
      ---
      
      Now, please write the next part of the story based on this instruction: "${chapterOutline}"
      
      Write approximately ${Math.round(wordCountPerChapter)} words for this section. Make it engaging, with dialogue and description.
    `;
    
    const response = await client.chat.completions.create({
        model: "gpt-4o",
        messages: [{ role: "system", content: systemPrompt }, { role: "user", content: userPrompt }],
        temperature: 0.7,
        max_tokens: 4096 // CRITICAL: Set max tokens to allow long chapter generation
    });
    
    const chapterContent = response.choices[0].message.content || '';
    debugData.push({ step: `generateChapter: ${chapterOutline.substring(0, 30)}...`, prompt: userPrompt, response: chapterContent });

    return chapterContent;
}


async function finalizeStoryDetails(client: OpenAI, fullStory: string, request: StoryRequest, moralOutcome: string, debugData: any[]): Promise<{ title: string; applicationQuestions: string[]; imagePrompt: string; }> {
  
  const systemPrompt = `You are a helpful assistant who creates supplementary materials for a children's story. Based on the complete story provided, generate a title, application questions, and an image prompt.`;
  const userPrompt = `
    Here is the complete children's story:
    ---
    ${fullStory}
    ---

    Based on the story above, please provide the following:
    1.  A creative and fitting "title".
    2.  Exactly 5 "applicationQuestions" that help children (ages 6-8) apply the story's lesson.
    3.  A short, descriptive "imagePrompt" for an illustrator. The prompt should describe a key scene from the story in a child-friendly, biblical illustration style.

    Respond with ONLY a valid JSON object in the format:
    {
      "title": "...",
      "applicationQuestions": ["...", "...", "...", "...", "..."],
      "imagePrompt": "..."
    }
  `;

  const response = await client.chat.completions.create({
    model: "gpt-4o",
    messages: [{ role: "system", content: systemPrompt }, { role: "user", content: userPrompt }],
    response_format: { type: "json_object" },
    temperature: 0.6,
    max_tokens: 2048
  });

  const responseContent = response.choices[0].message.content || '';
  debugData.push({ step: 'finalizeStory', prompt: userPrompt, response: responseContent });
  
  return JSON.parse(responseContent);
}
